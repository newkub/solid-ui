# Contributing

Thank you for your interest in contributing to `solid-ui`.

## Setup

```bash
bun install
bun run typecheck
bun run lint
bun run build
```

## Workflow

1. Fork the repository and create a branch.
2. Make your changes.
3. Run lint and typecheck.
4. Run `bun run review-codebase` and address findings.
5. Open a pull request.

## Conventions

- Use TypeScript with explicit types.
- Avoid `any` and non-null assertions.
- Follow Biome formatting and lint rules.
- Keep components small and focused.
- Add tests when adding features.

## Questions

Open an issue or discussion if you need help.
